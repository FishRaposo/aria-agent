# Security policy

Boundaries: default offline-first demo, approval gating, redaction, replay and
the strict launch profile are covered in [docs/security.md](docs/security.md) and
[docs/EVIDENCE.md](docs/EVIDENCE.md).

## Reporting a vulnerability

Open a [security advisory](https://github.com/FishRaposo/aria-agent/security/advisories/new)
or email fishraposo@gmail.com with the subject `[aria-agent security]`. Please do
not open a public issue for a security report.

## Supported versions

Security fixes target the latest tagged release and `main`.
