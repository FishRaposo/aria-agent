# Design brief — ARIA Agent

**Name:** ARIA
**Category:** Agent execution-control console and recruiter demo.
**User:** An engineer or reviewer deciding whether an agent can be trusted with a consequential action.
**Job:** Follow one request through validation, permission, human approval and verified execution; inspect the trace and the boundary.
**Artifact:** The execution record: request, proposed tool, permission decision, approval state, result and trace.
**Evidence:** A single-use approval bound to the action, a visible denial, inspectable spans, saved skill evidence and a real project setup.
**Drift to refuse:** indigo AI-console palette, glow gradients, tiny labels, icon-only mobile navigation, undifferentiated story cards, decoration over the boundary.
**Register:** Brand for the landing; product for the console.
